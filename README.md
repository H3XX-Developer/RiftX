## 🟦 What is RiftX?

<div align="center">

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=600&size=20&duration=3000&pause=800&color=00D4FF&center=true&vCenter=true&width=650&height=35&lines=Browse.;Download.;Install.;Play.;All+on+your+Xbox+360." alt="What"/>

</div>

**RiftX** is a standalone homebrew launcher and app/game store for
jailbroken Xbox 360 consoles. It's designed to replace the need for a PC
just to install homebrew content.

### What it actually does

- 🎬 **Plays an intro video** when the launcher starts (skippable)
- 🖼️ **Shows a splash screen** for a moment before loading
- 🛒 **Loads a live catalog** of apps and games from a static JSON file
- ⚡ **Installs with one button press** — no PC, no USB, no file transfers
- 🔐 **Verifies every download** with SHA-256 hashes before install
- 🔄 **Checks for updates** to itself and installed apps automatically
- 📴 **Works offline** after the first catalog load (cached for 24 hours)
- 🎮 **Built for the controller** — no keyboard, no mouse, no typing

### What it doesn't do

- ❌ No login, no accounts, no registration
- ❌ No telemetry, no tracking, no analytics
- ❌ No ads, no monetization
- ❌ No internet requirement after first launch (except for new downloads)
- ❌ No access to system files
- ❌ No Xbox Live integration

## 📩 Want Your App on RiftX?

**Are you a developer?** Do you have a homebrew app, game, mod menu, or
tool you'd like added to the RiftX catalog?

### How to submit your app

1. **Join our Discord** — [PASTE_DISCORD_LINK_HERE](PASTE_DISCORD_LINK_HERE)
2. **Open a ticket** in the **#submit-app** channel
3. **Include in your ticket**:
   - App name
   - Your name / author name
   - Short description (what it does)
   - Version number
   - Download link (direct `.xex` file)
   - Icon image (128×128 or 256×256 PNG)
   - SHA-256 hash of the `.xex` file
   - Any screenshots (optional)

### What happens next

- ✅ Your app gets **reviewed** by the RiftX team
- ✅ If approved, it's added to the **live catalog**
- ✅ It appears in RiftX on every user's console **instantly**
- ✅ You're credited as the author
- ❌ If rejected, you'll be told why and can fix + resubmit

### Rules for submissions

- 🚫 **No malware, miners, or harmful code**
- 🚫 **No apps that steal data or credentials**
- 🚫 **No paid-only content** (RiftX catalog is free)
- ✅ **Open to homebrew, mod menus, tools, emulators, games**
- ✅ **Credit goes to the original author** — always
- ✅ **You keep ownership** of your app — RiftX just hosts it

**I do not claim ownership of any submitted apps.** Your work, your credit.

> ⏳ **Reviews happen on weekends** — please allow extra time.

## 🛡️ Is RiftX Safe?

**Yes — it's designed from the ground up to be safe.** Here's exactly what
it does and doesn't touch:

### ✅ What RiftX does to your console

- Creates a folder at `Hdd:\RiftX\` for its own files
- Creates `Hdd:\RiftX\Apps\` for installed homebrew
- Creates `Hdd:\RiftX\Downloads\` for temporary downloads
- Creates `Hdd:\RiftX\Cache\` for catalog cache
- Creates `Hdd:\RiftX\Logs\` for error logs (helps with bug reports)
- Reads/writes only within `Hdd:\RiftX\`
- Connects to **GitHub Pages** to fetch the catalog and download files

### ❌ What RiftX does NOT do

- Does NOT modify system files
- Does NOT touch your dashboard or kernel
- Does NOT access your profile, saves, or game data
- Does NOT install anything outside `Hdd:\RiftX\Apps\`
- Does NOT phone home, send telemetry, or track usage
- Does NOT require elevated permissions
- Does NOT interfere with Xbox Live (when not in use)

### 🔐 Download integrity

Every single file RiftX downloads is **SHA-256 verified** against a hash
listed in the catalog. If the hash doesn't match:

- ❌ The download is rejected
- ❌ Nothing is installed
- ❌ A clear error is shown

**Tampered or corrupted files cannot be installed.**

### 🧯 Safe removal

RiftX can be fully removed at any time by deleting `Hdd:\RiftX\`.
**Nothing else is touched.** No registry, no system folder, no leftovers.

### ⚠️ Honest notes

- **Homebrew in general** carries some risk — not because of RiftX, but
  because of the third-party apps and mod menus it can install
- **Online play** with mods can result in an Xbox Live ban — this is true
  of any homebrew, not RiftX specifically
- **Use single-player** whenever installing mods for the safest experience
- **RiftX itself is safe** — what you install through it depends on the
  catalog

## ❓ FAQ

**Is RiftX open source?**
No. RiftX is proprietary software and the source code is private.

**Is RiftX released yet?**
No. It's in active private development.

**Who makes RiftX?**
Just one person — **H3XX-Dev**. It's a solo project.

**Why do updates take so long?**
Because it's a solo project, and I only code on weekends. Weekdays are for
real life. Updates will be a bit long but we will get there.

**When will it be released?**
After private beta testing confirms it's stable. No set date.

**Is it safe for my console?**
Yes — RiftX only touches `Hdd:\RiftX\` and verifies every download. See
the **Is RiftX Safe?** section above for full details.

**What consoles does it support?**
RGH and JTAG fully. ABadUpdate and ABadAvatar are being tested.

**Will it get me banned on Xbox Live?**
RiftX itself doesn't interact with Xbox Live. Installing mods and playing
online can get you banned — that's a risk of homebrew in general, not
RiftX specifically.

**Can I submit my own app to the catalog?**
Yes! [Open a ticket on our Discord](PASTE_DISCORD_LINK_HERE) with your app
details. See the **Want Your App on RiftX?** section above. Reviews happen
on weekends.

**Can I contribute to RiftX itself?**
Not at this stage. Once private beta is running, contributors will be
invited.

**Where do I get it when it's released?**
Right here on this repo's releases page.

**Can I fork this repo?**
The repo is public but the software is proprietary. You can view it for
reference, but the source code is not open source and cannot be reused,
redistributed, or claimed as your own.
